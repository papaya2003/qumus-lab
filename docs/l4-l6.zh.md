# L4 / L5 / L6：单个动作、整段流程、脚本化 Hall bar

11-10 晚写成，**只在 `--demo` 里跑过，没有碰过真机**。真机要等 L3 把点位量完（见最后一节）。

## 三层是什么

| 层 | 是什么 | 代码 | 例子 |
| --- | --- | --- | --- |
| L4 | 一个 v1 “molecule” 级别的动作，按 v1 的 G-code 顺序和数值照搬 | `qumus_lab/ops/` | 把芯片放上转移台、装印章、找接触点、拾取、放下 |
| L5 | 一整段流程（job），名字和参数跟模拟实验室 qumus-simlab 完全一样，brain 不用分辨是真是假 | `qumus_lab/flows/` | `exfoliate_chips`、`search_chip`、`stack_device` |
| L6 | 不用 AI 的固定脚本，从剥离一直做到 Hall bar | `qumus_lab/hallbar_script.py` | hBN + Gr 叠在电极芯片上 |

L5 的 job 一发出去马上回一个 `run_id`，之后每一步（step）都写进 qumus.db，brain 通过
`GET /api/records` 看进度。停止（stop）或者租约断了，正在跑的 job 在下一个检查点停下，排队的也取消。

## 怎么在 demo 里看

```bat
scripts\start-demo.bat            :: 或 python -m qumus_lab.launcher --demo --demo-speed 50 --demo-reset
python -m qumus_lab.hallbar_script --exfoliation http://127.0.0.1:8781 --stacking http://127.0.0.1:8782
```

`--demo-reset` 把 demo 的台面恢复成起始状态（和 simlab 一样的编号：chip_001…009、carrier_gr_01、
carrier_hbn_01、chip_e01 电极芯片、stamp_01…03、tape）。调试网页 8780 的显微镜画面会跟着样品台、
物镜、印章变化：能看到 flake、印章压下去时的牛顿环、最后叠好的 hBN/Gr。

## 同一台电脑 / 不同电脑

脚本和 brain 只用 HTTP（contract v1），不读任何文件，所以只换网址：

| brain 在哪 | 网址 |
| --- | --- |
| 同一台电脑 | `http://127.0.0.1:8781` / `8782` |
| 另一台电脑，SSH 隧道 | 隧道在 brain 那头的端口，例如 `http://127.0.0.1:18781` / `18782` |

本机模拟隧道：`python -m qumus_lab.tunnel_sim 18781:127.0.0.1:8781 18782:127.0.0.1:8782`。
测试 `tests/test_l6_hallbar.py` 把整个 Hall bar 直接跑一遍、再经过模拟隧道跑一遍，两次结果一样；
隧道那头仍然不能发 local-only 动作（jog、set_switch、unlock），这些只能在实验室电脑的 8780 上做。

## L6 脚本做了什么

1. `exfoliate_chips` hBN 一片，再 Gr 一片（需要时先做 mother tape）
2. 两片各做一次 `search_chip`（扫描、20x 复查、放回）
3. 选 flake：hBN 选 10-20 / 20-30 nm 里面积最大的；Gr 选比 hBN 一半还小的单层里最大的
4. `stack_device [hBN, Gr]` 到电极芯片：v1 Hall 器件顺序（起始温度 90 C → 装印章 → 每个 flake：
   上台、20x 找回、初始化印章、第一个 flake 找接触点、拾取、移走印章、检查拾取、放回 → 电极芯片：
   对准、初始化印章、加热到 155 C 下压到 z 4.9、超过 170 C 后 16 V、抬起 5 mm → 拍 5/10/20/100x → 回收印章）
5. `cool_experiment_stages`

demo 结果：Gr 落在电极中心约 3 µm，hBN 约 16 µm（5x 下一个像素约 3 µm）。

## 和 v1 不一样的地方（都要你知道）

- **找 flake 不是 v1**：v1 用的 ML 分割模型不在仓库里。现在是按颜色对比度的占位检测器，只对 demo
  画面调过，真芯片没测过。Edward 的检测器用 `vision.set_detector(...)` 换上即可（docs/vision.md）。
- **拾取检查是新加的**：印章移走后看拾取位置是否还有 flake（v1 只存照片）。没拾起来 job 就失败。
- **印章 z 下限 4.9 mm**（防撞）：找接触点和拾取往下走不会低于 v1 自己用过的最低值 4.9。
- 放下目标暂时是“离芯片中心多少 mm”，还没有角点检测和 GDS 对准。
- `cool_experiment_stages`、`inspect_bench` 只管发到的那个模块自己的加热台 / 桌面相机；simlab 把它们
  都放在 stacking 上（已记在 open-questions，要和 brain 线程对一下）。
- job 只有 `job_cancel` 和 `job_status`；simlab 还有 retry / resume / reverify / review_waiting，还没做。

## 真机之前必须先做的（L3）

- 左右板每个槽位、印章槽的坐标（现在是 `source: sketch` 草图值，真机模式会拒绝）。
- 样品台 x/y 的量程（真机模式下按图像算出来的移动会被拒绝，直到 limits.yaml 写入 measured）。
- 转移台加热器的标定（未标定时只能 ≤ 40 C，v1 的 90/155/170 C 会被拒绝）。
- 对焦 25 mm 的移动需要量好的对焦范围。
- 图像方向（样品台动 0.5 mm 看画面往哪边走）和光轴中心像素。
